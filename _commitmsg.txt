chore: retire MixTox_shiny_v2 prototype in favour of run_app() (#4, #5)

mixdra::run_app() is the maintained, documented Shiny app (Single / Binary /
Ternary, CSV upload + schema validation + visible errors). MixTox_shiny_v2 was
Sam's earlier paste-based prototype (Single + Binary only) and is fully
superseded by it; keeping both in the repo caused confusion (#4 was filed
against the prototype).

- Remove MixTox_shiny_v2/ (app, modules, model_functions.R, Test_dataset).
- Remove tools/port_models.R: a one-shot script that ported the prototype's
  model_functions.R into the package; the port/model-unification is complete,
  so it no longer has a source to read.
- Update helper-legacy-models.R provenance comments to note the prototype has
  been retired (the legacy oracle keeps its own verbatim copies, so the test
  suite is unaffected -- verified it still sources cleanly).
- Drop the now-stale ^MixTox_shiny_v2$ entry from .Rbuildignore.
